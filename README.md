# NYC Airbnb Data Summary Tool

## Project Overview

This project is developed by Group 1 as part of the
CPSC620 course at the University of Niagara Falls Canada.

The objective is to develop a modular Python tool
to clean, process, and summarize NYC Airbnb listing data.

The project follows Agile development practices,
including sprint planning, user stories, task tracking,
version control, and team collaboration using GitHub.

## Sprint Goal

Develop a functional and reusable Python tool to clean
and analyze NYC Airbnb data, providing insights into
listing prices, neighbourhoods, room types,
availability, and reviews.

## Agile Methodology

The project is developed using one mini sprint.

The team uses GitHub Issues to define user stories,
acceptance criteria, and implementation tasks.

GitHub Projects is used to monitor task progress
through the following workflow:

To Do → In Progress → Done

Each member contributes through feature branches,
commits, pull requests, and peer reviews.

## How to Run

1. Clone the repository.
2. Install the required Python dependencies.
3. Place the Airbnb_NYC.csv dataset in the data folder.
4. Run the main.py file.

## Expected Outputs

The Python tool will generate summary statistics
and reusable data objects for Airbnb listings,
including price, neighbourhood, availability,
and review analysis.
